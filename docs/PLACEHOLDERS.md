# ข้อมูลที่รอจากเจ้าของร้าน

ข้อความที่ยังไม่มีข้อมูลจริงจะขึ้นต้นด้วย `[รอข้อมูล]` (ภาษาไทย) หรือ `[PLACEHOLDER]` (ภาษาอังกฤษ)
รูปตัวอย่างเป็นรูปสีเทาที่มีคำว่า PLACEHOLDER ก่อนเปิดเว็บจริงให้ค้นคำเหล่านี้ในหลังบ้านแล้วแก้ให้หมด

## แบรนด์
- [ ] โลโก้ไฟล์ vector (SVG / AI / PDF) และโลโก้สีขาวสำหรับพื้นเข้ม
- [ ] สีแบรนด์ (hex)
- [ ] สโลแกน / tagline (ไทย + อังกฤษ)
- [ ] รูป Open Graph สำหรับแชร์ลิงก์

## ช่องทางติดต่อ (ตั้งค่าเว็บไซต์)
- [x] เบอร์โทร
- [x] LINE ID และลิงก์ LINE OA
- [x] Facebook URL
- [x] Instagram URL
- [x] อีเมลร้าน
- [ ] อีเมลรับแจ้งเตือนฟอร์มติดต่อ
- [x] ที่อยู่หลัก (ที่อยู่ภาษาอังกฤษเป็นการถอดเสียงจากที่อยู่ไทย ให้ร้านตรวจ)
- [ ] รายชื่อสื่อที่พูดถึงเรา (ชื่อ, ลิงก์, โลโก้)

## สาขา
- [x] สาขาใหญ่: ชื่อ, ที่อยู่, เวลาเปิด, เบอร์มือถือ
- [ ] สาขาใหญ่: ลิงก์ Google Maps ของร้าน (ตอนนี้เป็นลิงก์ค้นหา), ลิงก์ฝังแผนที่, รูปหน้าร้าน
- [ ] สาขาอื่น (ถ้ามี)

## หน้าแรก
- [ ] Tagline ใน Hero และรูป Hero
- [ ] ข้อความ "รู้จักคุณแม่จู้"
- [ ] ตัวเลข 4 กล่อง (เช่น จำนวนปี) พร้อมคำอธิบาย
- [ ] รายละเอียดบริการ 4 การ์ด (บริการที่ 4 ยังไม่ทราบ)

## เกี่ยวกับเรา
- [ ] เรื่องราวของร้าน
- [ ] Timeline: ปีและเหตุการณ์แต่ละช่วง
- [ ] คำพูดของคุณหงวดจู้ สันติกุล และรูป
- [ ] การสะกดชื่อผู้ก่อตั้งเป็นภาษาอังกฤษ

## ใบรับรอง
- [ ] รายชื่อใบรับรอง โลโก้ และไฟล์ PDF

## บริการ
- [ ] รายละเอียดขายส่ง, ของฝาก/กระเช้า, OEM และบริการอื่นถ้ามี

## วิธีสั่งซื้อ
- [ ] วิธีชำระเงิน, ค่าจัดส่ง, ระยะเวลาจัดส่ง

## สินค้าและข่าว
- [ ] สินค้าจริงและข่าวจริง (เพิ่มเองผ่าน /admin ไม่ย้ายจากเว็บเก่า)
- [ ] คำอธิบายหมวดสินค้าแต่ละหมวด
